Contacts API

Manage contacts, contact lists, list members, tags, bulk operations and CSV import via the NorthRelay API.

Contacts API

The Contacts API stores recipient information, organizes contacts into lists, and manages tags for targeted campaigns. Every route on this page works with an API key (Authorization: Bearer nr_live_...) as well as from the dashboard.

To subscribe someone with consent evidence and double opt-in, or to unsubscribe them, use the Subscriptions API instead of writing contact status directly: it applies the opt-out rules, records consent and fires the contact.* and list.* webhooks.

Scopes

RoutesScope
GET on any /contacts/** route, and GET /contacts/exportcontacts:read
POST, PATCH, PUT, DELETE on any /contacts/** routecontacts:write

Response format

Contact routes (/contacts, /contacts/{id}, tags, bulk) use the standard envelope: { "success": true, "data": ... } on success and { "success": false, "error": { "code", "message", "fix_action", "docs_url" } } on failure. List routes (/contacts/lists/**) return { "data": ... }; their newer member endpoints also include success. Import returns the result object directly.

Get Contact

Returns the contact with its tags and customFields. Unknown ids and contacts of other accounts return 404 RESOURCE_NOT_FOUND.

For a contact's lists, topics and consent evidence in one call, use GET /subscriptions/{email}.

Create Contact

Rate limited to 60 requests per minute per client. For larger loads use bulk create or CSV import.

Update Contact

Only the fields you send are changed. Accepts email, firstName, lastName, phone, metadata, source and status. Use the tag routes for tags.

Status changes must follow the allowed transitions:

FromAllowed to
PENDINGACTIVE, UNSUBSCRIBED, CLEANED
ACTIVEUNSUBSCRIBED, BOUNCED, COMPLAINED, CLEANED
UNSUBSCRIBEDACTIVE, PENDING
BOUNCEDACTIVE
COMPLAINED, CLEANEDnone (terminal)

An invalid transition returns 400 INVALID_STATUS_TRANSITION. Changing status here only updates the contact; it does not add or lift suppressions or fire webhooks. To unsubscribe or resubscribe someone, use the Subscriptions API.

Delete Contact

Permanently deletes the contact, its tags, custom fields and list memberships. Suppressions are kept, so a deleted address that had unsubscribed stays suppressed.

CSV Import

Imports a CSV file using multipart form data. New addresses are created as ACTIVE contacts with source CSV_IMPORT and consent source import; existing addresses are counted in skipped and not updated.

FieldTypeRequiredDescription
fileCSV fileYes.csv, up to 2 MiB and 1,000 data rows plus the header row
mappingsJSON stringYesArray of { "csvColumn": "<header>", "field": "email" | "firstName" | "lastName" | "phone" | "skip" }. csvColumn must match a header exactly. Exactly one column must map to email.
listIdstringNoAdd every imported contact, and every existing contact found in the file, to this list
tagsstringNoComma-separated tags applied to newly created contacts (up to 20)

Headers must be unique. Quoted commas, escaped quotes and multiline fields are supported. Maximum 100 columns and 4,096 characters per field; multipart overhead is capped at 64 KiB. Split larger imports into separate requests.

StatusWhen

Importing never clears suppressions: an address that bounced, complained or unsubscribed stays suppressed, and campaigns skip it. Only import addresses that agreed to receive your mail; import does not fire contact.subscribed or list.member_added webhooks.

Contact Lists

Lists are named audiences for campaigns. A list can be tagged with a topic (suppressionGroupId): recipients who opt out of that topic leave the list and are skipped when you send to it. See Suppressions: topics.

Archive a contact list

Archives the list (isArchived: true). Contacts and memberships are kept. Returns { "success": true }.

List Members

List members

ParameterTypeDefaultDescription
pageinteger1Page number
limitinteger50Items per page (max 100)
filterstringallall, active (no suppression flags) or suppressed

Campaigns go only to current members whose contact is not PENDING. suppressionStatuses lists every reason the member will not receive mail: REMOVED_FROM_LIST (unsubscribed from this list), UNSUBSCRIBED, BOUNCED, COMPLAINED, CLEANED, MANUALLY_SUPPRESSED, CATEGORY_SUPPRESSED (opted out of the list's topic).

Add members

Add existing contacts by id and/or email. With createMissing: true, unknown emails are created as ACTIVE contacts (source API) first.

FieldTypeRequiredDescription
contactIdsstring[]One of contactIds / emailsUp to 1,000 contact ids
emailsstring[]One of contactIds / emailsUp to 1,000 addresses
createMissingbooleanNoCreate contacts for unknown emails. Addresses that unsubscribed, bounced, complained or are blocked are not created; they are reported in blocked.
FieldDescription
data.addedContacts added (or restored after an earlier removal)
data.alreadyMembersContacts that were already current members
data.notFoundIds not in your account, and unknown emails when createMissing is not set
data.blocked{ email, reason } for unknown emails that could not be created; reason is a Subscriptions error code such as RECIPIENT_UNSUBSCRIBED, RECIPIENT_SUPPRESSED or FREE_TIER_CONTACT_LIMIT
added, skipped, messageKept for older clients; skipped equals data.alreadyMembers

Existing contacts are added as they are; send-time suppression still skips any that unsubscribed, bounced or complained. A list.member_added webhook fires for each added member. A list that is not yours returns 404 LIST_NOT_FOUND.

Remove members

Remove by body { "contactIds": [...], "emails": [...] }, or a single member with ?contactId= or ?email=.

This is the list owner removing someone: the membership is deleted and a list.member_removed webhook fires (source: "API"). It is not an unsubscribe; the contact can be added again. To record that a recipient asked to leave, use POST /subscriptions/unsubscribe with scope: "list".

CodeStatusFix
VALIDATION_ERROR400Send contactIds or emails, or ?contactId= / ?email=
NOT_A_MEMBER404None of the contacts is in the list. Check with GET /contacts/lists/{id}/members
LIST_NOT_FOUND404Check the list id with GET /contacts/lists
